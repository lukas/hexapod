# First-write audit implementation package

**Prepared and preregistered, awaiting root implementation review. No archived first-write diagnostic output or new simulator response has been generated.**

The runner imports only standard-library modules and NumPy. It loads existing saved arrays and JSON; it has no policy, environment, rollout helper, servo-profile, MuJoCo or hardware interface. All 58 input hashes and its own recorded SHA must match. Outputs go into a newly created directory; the runner refuses to overwrite an existing result and preserves partial records/failure details if a check fails.

The six original control-chain cells validate all 6,020 rows before the 32 first-write calculations. Policy/environment action dtype is required to remain float32; decoded/safe/write fields remain float64. The original pulse operation includes a float32 applied-dose subtraction, which is compared exactly with the archive. Changing that subtraction to float64 would alter the archived numerical receipt. Only already declared decoder/safety/frame reconstruction arithmetic permits 2e-15 rad absolute error, never first-dose equality or exact-zero masking classification.

All eight onset identities come from the original selected-state file. The first action uses row P, matching the shared complete state after P ticks. Each archived signed branch must match that prefix and the original canonical frozen vector. The eight zero calculations are exact. The runner consumes no later branch actions, computes no body/yaw response and never substitutes baseline actions for the remaining four pulse ticks.

The independent test author implemented and ran **63 tests**, all passing via uv. They compare safety projection with an AST-extracted tail of the exact hash-checked SafetyLayer.filter, including joint limits applied after slew; compare native mapping with the pinned pure joint_frame implementation, including hip-to-knee coupling; verify exact-zero classification and undefined zero-dose ratios; exercise original float32 injection rounding; reject changed dtype, signed zero, shape, missing write, reordered index, nonfinite values, active entry ramp, unhealthy status and altered synthetic transfer records. Synthetic fixture output is generated by the pinned source arithmetic, not copied from the proposed implementation. No model or simulator is imported. The tests exposed a missing policy-action dtype guard during preparation; it was repaired before the preregistration freeze. Test source paths are repository-relative with pinned hash checks.

This package has no new success/failure threshold for walking. A valid audit establishes only first-write transmission arithmetic. Existing nonzero body outcomes already exclude complete five-tick causal masking for those branches, while an unchanged first write does not show that subsequent writes were unchanged. Delayed profile response, plant motion and yaw benefit remain outside the scope; all original STOPs and gates remain intact.
