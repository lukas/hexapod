# Hexapod Walker

A family of six-legged walking-robot designs, from a tabletop 3D-printed
prototype up to a human-carrying vehicle.

| Directory | What it is |
|---|---|
| [`prototype_sts3215/`](prototype_sts3215/) | **Current robot** — Feetech STS3215 serial-bus servos, Arduino UNO Q brain, full CAD validation pipeline, MuJoCo RL stack, CoreWeave orchestrator, web control, and the `hexapod-tracker` submodule. See [`prototype_sts3215/PROTOTYPE.md`](prototype_sts3215/PROTOTYPE.md), [`prototype_sts3215/docs/CAD_WORKFLOW.md`](prototype_sts3215/docs/CAD_WORKFLOW.md), and the [`concepts/` index](prototype_sts3215/concepts/README.md). |
| [`prototype_ak40/`](prototype_ak40/) | AK40-actuator concept variant (BuildViz-registered). |
