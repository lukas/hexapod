# Hexapod Walker

A family of six-legged walking-robot designs, from a tabletop 3D-printed
prototype up to a human-carrying vehicle.

| Directory | What it is |
|---|---|
| [`prototype_sts3215/`](prototype_sts3215/) | **Current robot** — Feetech STS3215 serial-bus servos, Arduino UNO Q brain, full CAD validation pipeline, MuJoCo RL stack, CoreWeave orchestrator, web control. See [`prototype_sts3215/PROTOTYPE.md`](prototype_sts3215/PROTOTYPE.md) and [`prototype_sts3215/CAD_WORKFLOW.md`](prototype_sts3215/CAD_WORKFLOW.md). |
| [`prototype_ak40/`](prototype_ak40/) | AK40-actuator concept variant (BuildViz-registered). |
| [`archive/`](archive/) | Frozen earlier generations: `fullsize_v1` (human-carrying walker), `prototype_v1` (hobby-servo prototype), `sts` (first STS3215 walking stack), `rideable_v1`/`rideable_v2` (rideable design studies), `hex` (legacy command CLI). See [`archive/README.md`](archive/README.md). |
